## 🔧 Local Viewing

To view the manual locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/smarttuningnusantar/BYD-Song-Plus-EV-Maintenance-Manual.git
   cd BYD-Song-Plus-EV-Maintenance-Manual
   ```

2. Open `docs/index.html` in your web browser

3. Or use a local server:
   ```bash
   # Python 3
   python -m http.server 8000 --directory docs
   
   # Then visit: http://localhost:8000
   ```

## 🌐 GitHub Pages Configuration

This project uses GitHub Pages with the `docs/` folder as the source. The repository is already configured to serve from the `docs` directory.

To modify GitHub Pages settings:
1. Go to Settings → Pages
2. Ensure "Source" is set to "Deploy from a branch"
3. Set "Branch" to `main` and folder to `/docs`
