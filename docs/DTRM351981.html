Front Wall Thermal Insulation Assembly - Removal and Installation

Removal

  1. Power off the low voltage electrical system. See Power-off and Power-on of Low Voltage Electrical System

  2. Remove the ventilation cover assembly. See Ventilation Cover Assembly - Removal and Installation

  3. Remove the pipe beam welding assembly components. See Pipe Beam Welding Assembly Components - Removal and Installation

  4. Remove the HVAC assembly. See HVAC Assembly - Removal and Installation

  5. Remove the brake pedal assembly. See Brake Pedal Assembly - Removal and Installation

  6. Remove the electronic accelerator pedal assembly. See Electronic Accelerator Pedal Assembly - Removal and Installation

  7. Remove the left domain control module guard. See Left Domain Control Module Guard - Removal and Installation

  8. Remove the right domain control module guard. See Right Domain Control Module Guard - Removal and Installation

  9. Remove the right domain control module bracket. See Right Domain Control Module Bracket - Removal and Installation

  10. Disconnect one connector.

  11. Pry up 7 fixing clips.

  12. Pry up 5 fixing clips.

  13. Remove 2 fixing bolts.

    • Tightening torque: 9N • m

  14. Disconnect 2 connectors.

  15. Pry up 3 fixing clips.

  16. Pry up 1 fixing clips.

  17. Pry up 5 fixing clips.

  18. Pry up 3 fixing clips.

  19. Remove 1 fixing clips.

  20. Remove 3 fixing clips.

  21. Remove 3 fixing clips, and take out the front wall thermal insulation assembly.

Installation

  1. Follow the removal steps in reverse order to install.
