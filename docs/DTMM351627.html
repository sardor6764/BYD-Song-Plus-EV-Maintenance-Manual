Instrument panel cluster assembly

System Function Principle

The instrument panel cluster is located in front of the driver and provides the required vehicle operating parameters, faults, mileage and other information.

The instrument panel cluster applies LCD, which can provide the necessary visibility. Each indicator of the instrument panel cluster is displayed through the LCD. The connecting circuit connects the instrument panel cluster to the electrical system of the vehicle. The connecting circuit is integrated in the vehicle wiring harness, routed in different positions, and fixed in many different ways.

Meters:

Name

Description

Speedometer

Based on the wheel speed sensor, ABS converts the wheel speed signal into vehicle speed signal and transmits the data to the instrument panel cluster through CAN.

Power meter

The power meter calculates based on the power of the battery management system. The instrument panel cluster calculates the power by collecting the total voltage and current sent by the power battery management module on the CAN, and determines the positive and negative.

Electricity meter

The instrument panel cluster collects the CAN information of the power battery management module and displays the battery capacity.

Warning and indicator lights:

Name

Icon

Working logic

Turn signal indicator

The instrument collects the turn signal of the combination switch through hardwire.

High beam indicator

When the instrument panel cluster receives the CAN message that the high beam is ON, this indicator will turn on. When receiving the CAN message that the high beam is OFF, this indicator will go out. The indicator and the high beam work synchronously.

Clearance light indicator

Receive the clearance light switch signal (CAN) from the combination switch.

Rear fog light indicator

Receive the rear fog light switch signal (CAN) from the combination switch.

Seat belt alarm indicator

Receive the seat belt switch signal (CAN) from the left domain control module.

SRS fault warning light

Receive the airbag fault signal from the supplemental restraint system.

ABS fault warning light

Receive the ABS fault information from the gateway and turn on the indicator. When the CAN line is broken, this indicator turns on.

Parking system fault warning light

Receive parking signal from the parking brake switch (hardwire). Receive the brake fluid level signal from the brake fluid level switch (hardwire). When the instrument panel cluster collects the "EBD fault" signal (CAN)

Steering system fault warning light

CAN communication transmission. EPS control unit sends EPS fault indication signal to the instrument panel cluster, whose CPU commands to turn on the indicator.

Smart key system warning light

Read the key information (CAN) from the smart key system.

Cruise control master indicator

CAN communication transmission. The motor control module sends the switching value signal to the instrument panel cluster. The instrument CPU processes the indicator state according to the signal.

Cruise control indicator

CAN communication transmission. The motor control module sends the switching value signal to the instrument panel cluster. The instrument CPU processes the indicator state according to the signal.

Main alarm indicator

Receive and prompt fault information (except backlight adjustment, door and trunk state information).

Low voltage power system warning light

The CAN line transmits the DC and charging system fault signals, and the instrument panel cluster controls to the indicator to turn on.

Low power battery warning light

CAN communication transmission. The power battery management module sends the low battery pack alarm signal to the instrument panel cluster. CPU controls the indicator to turn on, which is synchronized with the electricity meter entering into the red area.

Charging connection indicator

Hardwire transmission. When the charge sensitive switch is closed, the instrument turns on the indicator. When the charge sensitive switch is disconnected, the instrument panel cluster turn offs this indicator.

Motor overheat warning light

CAN communication transmission. The motor control module sends the power motor overtemperature alarm signal to the instrument panel cluster, and instrument panel cluster CPU commands to turn on the indicator.

Powertrain fault warning light

When the fault signals of battery management system and M2 motor control module are collected by CAN communication, CPU commands to turn on the indicator.

OK indicator

The M2 motor control module sends the "READY” indicator on signal to the instrument panel cluster through CAN, and the instrument panel cluster CPU commands to turn on the indicator.

ECO indicator

CAN line transmission. The instrument panel cluster CPU commands to turn on the indicator.

SPORT indicator

CAN line transmission. The instrument panel cluster CPU commands to turn on the indicator.

Electronic parking indicator

CAN transmission. The instrument panel cluster collects the message signal with ID 0x218 forwarded by the gateway and gives corresponding instructions according to the messages.

High motor coolant temperature indicator

CAN communication transmits the alarm signal of high water temperature from the motor control module, and the instrument panel cluster CPU commands to turn on the indicator.

ESP fault warning light

ESP fault signal (CAN) is received from ESP.

ESP OFF warning light

ESP OFF signal (CAN) is received.

Tire pressure fault warning light

The tire pressure fault signal (CAN) is received from the tire pressure monitoring system.
