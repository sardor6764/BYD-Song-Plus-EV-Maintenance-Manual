Instrument Panel Cluster Cover Base Assembly - Removal and Installation

Removal

  1. Remove the instrument panel right end guard assembly. See Instrument Panel Right End Guard Assembly - Removal and Installation

  2. Remove Glove Box Upper Trim Panel Assembly. See Glove Box Upper Trim Panel Assembly - Removal and Installation

  3. Remove the PAD access cover assembly. See PAD Access Cover Assembly - Removal and Installation

  4. Remove the PAD display assembly. See PAD Display Assembly - Removal and Installation

  5. Remove the PAD mounting base guard assembly. See PAD Mounting Base Guard Assembly - Removal and Installation

  6. Remove the instrument panel right trim panel fitting assembly. See Instrument Panel Right Trim Panel Fitting Assembly - Removal and Installation

  7. Remove the instrument panel left end guard assembly. See Instrument Panel Left End Guard Assembly - Removal and Installation

  8. Remove the left lower guard trim panel assembly. See Left Lower Guard Upper Trim Panel Assembly - Removal and Installation

  9. Remove the instrument panel left trim panel assembly. See Instrument Panel Left Trim Panel Assembly - Removal and Installation

  10. Remove the combination switch upper guard assembly. See Combination Switch Upper Guard Assembly - Removal and Installation

  11. Remove the instrument panel cluster cover assembly. See Instrument Panel Cluster Cover Assembly - Removal and Installation

  12. Remove 4 fixing screws.

  13. Pry up 5 fixing clips, and take out the instrument panel cluster cover base assembly.

Installation

  1. Follow the removal steps in reverse order to install.
