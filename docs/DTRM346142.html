Inspection of Brake Caliper Guide Pin

Reminder

四个车轮的制动钳插销组件检查方法一致，下面以左前侧为例。

  1. Remove the left front wheel assembly. See Wheel Assembly - Removal and Installation

  2. Check the guide pin of the brake caliper.

    • Remove the dirt and check whether the dust boot of the brake caliper guide pin is cracked or aged. If yes, replace it.

    • Step on the brake pedal and check whether the brake caliper guide pin is stuck or abnormal. If it is, overhaul or replace it.

  3. Install the left front wheel assembly. See Wheel Assembly - Removal and Installation
