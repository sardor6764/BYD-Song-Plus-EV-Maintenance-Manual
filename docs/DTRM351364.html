Inclination Angle Calibration of Power Domain Control Module

Inclination Angle Calibration

Caution

After replacing the integrated intelligent front drive control module, use the VDS to conduct inclination angle calibration.

  1. Power on the vehicle and connect a VDS.

    1. Power on the vehicle and stop it in a horizontal position.

    2. Select “ECU Module”, conduct vehicle ECU module scanning.

    3. After the scan is completed, select "Power Domain Control Module" to enter the power domain control module diagnosis interface.

    4. Select "Inclination Angle Calibration" to complete the inclination angle calibration process.

    5. Check the “Data Flow” to see the inclination angle calibration state. If it shows “calibrated”, the inclination angle calibration is done successfully.
