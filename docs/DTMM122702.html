保养安全作业指南

基本安全要求

  1. 车上标注的“危险” 、“警告” 等标志，为安全提示信息，维护操作前或执行维修步骤前，应严格按照相关的提示及规定的安全操作要求执行。

    • “危险” 表明：如果不遵守规定的操作程序，将导致严重的伤害或死亡。

    • “警告” 表明：直接的危险，如果不遵守规定的操作程序，可能会导致严重的人身伤害。

  2. 高压零部件包括：高压橙色线束、动力电池系统、前驱电动总成、后驱电动总成、充配电总成、充电系统、电动压缩机及PTC加热器等。

  3. 电器电路维修人员必须持有高压电执业资质证书，并严格遵守电工安全操作规程。

  4. 维护高压部件时，必须按照要求穿戴无损的绝缘防护装备，作业用的维修工具必须是高压绝缘工具。

  5. 维护保养车辆时，严禁佩戴饰品、手表等。

  6. 严禁非专业人员对高压电缆、高压元件进行切割或打开作业。

  7. 严禁任何时候用双手同时触摸车辆高压元件的正负极柱。

  8. 严禁用水冲洗车辆高压零部件及电器舱。

  9. 严禁人为对车辆高压零部件进行破坏性行为。

检测安全要求

  1. 纯电车各级维护预检作业处于带电、可启动、可起步状态，预检作业必须由专业人员从事。

  2. 车辆上电前，应确认无其他人员在进行维修作业，应确保车辆已实施驻车制动并处于空挡位置。

  3. 车辆上电后，应在方向盘部位悬挂“严禁擅动” 等警示标识。

  4. 车辆检测、诊断、竣工检验前，须对绝缘手套进行绝缘测试，严禁使用破损的绝缘手套，检测仪器需要确认工作良好后方可使用，避免故障仪器输出虚假数值而导致高压事故。

  5. 严禁裸手直接触摸各橙色线束、高压接插件和高压部件。

  6. 严禁用手指、小工具金属端或铁条等接触到高压电缆接插件中的端子。

  7. 用万用表测高压接线端电压时，严禁用手触碰表笔导电体。

维修安全要求

  1. 车辆施工作业前，车辆应进入维护作业区，放置“高压危险” 、“禁止进入” 警示牌，禁止非维护人员入内，警示牌只能由维护人员摘除。

  2. 车辆施工作业前，应确保车辆解除高压电。

  3. 车辆施工作业时，拆卸的所有零部件数应予以记录并放置在干净、可视区域的零件盘内，装复时保证所有零部件都安装到位，无余件或缺件情况，严防螺栓等细小部件掉入高压部件内部。

  4. 车辆维修保养时，拆卸的高压部件的电缆正、负极接插件，需用专用绝缘堵盖或绝缘胶带进行绝缘防护处理。
