Instrument Panel Duct Assembly - Removal and Installation

Removal

  1. Remove the instrument panel cluster cover assembly. See Instrument Panel Cluster Cover Assembly - Removal and Installation

  2. Remove the instrument panel cluster cover base assembly. See Instrument Panel Cluster Cover Base Assembly - Removal and Installation

  3. Remove the instrument panel cluster assembly. See Instrument Panel Cluster Assembly - Removal and Installation

  4. Remove the console body assembly components. See Console Body Assembly Components - Removal and Installation

  5. Remove the inside temperature sensor. See Inside Temperature Sensor - Removal and Installation

  6. Remove the instrument panel upper body components. See Instrument Panel Upper Body Components - Removal and Installation

  7. Remove the channel temperature sensor (instrument panel left face duct assembly). See Channel Temperature Sensor (Instrument Panel Left Face Duct Assembly) - Removal and Installation

  8. Remove the channel temperature sensor (instrument panel right face duct assembly). See Channel Temperature Sensor (Instrument Panel Right Face Duct Assembly) - Removal and Installation

  9. Remove 8 fixing screws.

  10. Remove one fixing screw

  11. Remove 2 fixing screws, and take out the instrument panel duct assembly.

Installation

  1. Follow the removal steps in reverse order to install.
