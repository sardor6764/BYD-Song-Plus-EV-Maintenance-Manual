System Function Principle

  1. The smart key system (integrated into the left domain control module) allows the driver to unlock the doors, power on, and start the vehicle from a distance using the smart key.

  2. PEPS supports electronic key, NFC key, cloud service and Bluetooth key, which are used through different communication modes and different key forms.

  3. PEPS shall be compatible with AES and Hitag2 algorithms. If VCU/ECM is based on Hitag2 algorithm (bit 2.4 of 20A is 0, and 0 is sent by default), the anti-theft verification conducted by PEPS and VCU/ECM shall be based on Hitag2 algorithm, which is consistent with the mass production state. If AES encryption algorithm is applied (bit 2.4 of 20A is 1, and 0 is sent by default), the newly defined anti-theft verification will be performed.

  4. The detection system is composed of 6 detection antenna assemblies (4 inside the vehicle and 2 outside the vehicle) and one high-frequency receiving module to detect the effective range inside and outside the vehicle.
